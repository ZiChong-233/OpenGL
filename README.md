# OpenGL Learning

基于 OpenGL 的图形学学习与实践项目。

## 开发环境

* Windows 11
* Visual Studio 2022
* CMake
* OpenGL 4.6
* GLFW
* GLAD
* GLM
* stb_image

## 项目结构

```text
src/        C++ 源代码
include/    头文件
shaders/    GLSL 着色器
assets/     纹理、模型等资源
```

## 构建方式

使用 CMake 配置并生成 Visual Studio 工程，然后编译运行。

## 当前内容

* OpenGL 窗口与渲染循环
* 着色器加载与管理
* 纹理加载
* 坐标变换
* 相机控制

## 说明

本项目用于个人 OpenGL 与计算机图形学学习。
